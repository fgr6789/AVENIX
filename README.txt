AVENIX GPLAY WEB — версия 1.0

Содержимое:
- index.html — главная страница
- style.css — оформление
- app.js — управление пультом и плитками
- manifest.webmanifest / icon.svg / sw.js — PWA-ресурсы

ВАЖНО:
Это веб-лаунчер, а не установщик системных приложений YaOS.
Для открытия на телевизоре сайт нужно разместить на HTTPS-хостинге,
затем открыть его адрес в Яндекс Браузере телевизора.
Внешние сервисы открываются в браузере и могут иметь ограничения на ТВ.
Плитки «Игры» и «Помощник» пока демонстрационные.
