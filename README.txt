AVENIX GPLAY WEB — версия 2.0

Что нового:
- Раздел GAMES с браузерными играми.
- Категории и поиск.
- Управление с клавиатуры и пульта: стрелки + OK/Enter.
- Игры открываются на сайтах игровых издателей/платформ. Для возврата используйте кнопку «Назад».

Установка обновления:
Загрузите файлы из этой папки в корень GitHub-репозитория AVENIX и подтвердите замену одноимённых файлов.
GitHub Pages обновит сайт автоматически через некоторое время.

Важно:
Это веб-лаунчер для YaOS, а не Android-приложение.
Совместимость игр с конкретным браузером телевизора зависит от сайта игры и возможностей телевизора.
Некоторые игры могут не поддерживать управление пультом.
